# Issue tracker: Backlog.md

Issues and structured work for this repository are Backlog.md tasks stored
under `backlog/`.

## Workflow

- Start each request with `backlog instructions overview`.
- Search before creating: `backlog search "<query>" --plain`.
- Read the relevant lifecycle guide before creating, executing, or finalizing tasks.
- Use `backlog task` commands for task changes.
- Do not edit task markdown files directly.

## When a skill says "publish to the issue tracker"

Create a Backlog task using the CLI.

## When a skill says "fetch the relevant ticket"

Run `backlog task view <task-id> --plain`.
